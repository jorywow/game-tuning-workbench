# Changelog

## 0.4.1-beta.1 - 2026-10-04

- 修复多页面使用时权限状态不同步：准备、保存和撤销前核对当前会话，切回“先看看”后同步按钮状态，并提供重新授权入口。
- 工作台服务重启后要求刷新页面，避免旧页面沿用新会话的权限令牌。
- 识别运行时可达、实际消费的常见平铺数值配置和独立命名常量，支持精确草稿、预览、确认应用和撤销。
- 缺少可调参数时说明内联数值需要项目级接入，避免误导为通用失效滑杆。
- 扩展精确写回器以支持 `ROOT.field`，保留行号和原值漂移检查。

## 0.3.0 - 2026-09-13

- 世界观卡片支持独立草稿和 `edit-worldview` ChangeSet。
- 玩法规则支持“当 / 如果 / 那么 / 玩家反馈”独立草稿和 `edit-gameplay` ChangeSet。
- 素材槽位支持 provider-neutral 生成简报和 `replace-asset` ChangeSet。
- ChangeSet 升级到 `0.2.0`，每项操作显式声明 `automatic` 或 `codex-assisted`。
- 本地应用引擎拒绝语义操作，避免只读证据被误当成直接写入权限。
- 完整 ChangeSet 支持复制与下载，数值自动应用与 Codex 辅助实施相互隔离。
- 增加插件发布打包、安装和升级说明。

## 0.2.0

- 增加应用记录、试玩清单、截图证据、验证状态和精确撤销。
- 增加不写真实源码的 Three.js A/B 临时运行预览。

## 0.1.0

- 增加 Three.js 分析器、只读工作台、数值草稿和确认应用基础流程。
# 0.4.0-beta.1

- 增加一句话启动入口、首次使用向导和统一渐进式工作台。
- 草稿迁到本地服务；会话级授权、请求校验、过期草稿提示。
- Codex 只读方案工作者、复杂修改确认、文件回执、受保护撤销和中断恢复。
- 故事参考图、可视化规则流程、素材图片候选对比。
- 自动运行错误/画布/截图证据；与人工玩法验收明确区分。
- 增加公开发布前置检查，排除个人分析结果。公开发布身份与许可证仍待确认。
