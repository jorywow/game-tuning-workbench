# 本轮验收记录

范围：0.4.0-beta.1 小白工作台；使用隔离测试游戏进行写入测试，已有游戏只作分析/启动检查。

## 已实际执行

- 自动化：原有分析、数值绑定、草稿、应用、截图记录测试，加上新服务的授权、确认、重复提交、并发任务、源码冲突、复杂回执、中断恢复、候选图片、过期草稿备份和过期证据保护。
- 服务集成：旧版应用、旧版数值预览、新版统一服务、复杂文本方案临时预览。
- 官方插件与技能格式校验、模型/修改单契约校验。
- 浏览器：“先看看”滑杆禁用；同页开启修改；速度 5 → 8 保存到草稿；刷新恢复；确认前禁用保存；数值保存、构建与撤销。
- 真实 Codex 交接：点击页面按钮，把测试故事“星空里的冒险”改为“海底的冒险”。不是模拟执行器。返回待确认方案后，在临时副本看到了新故事；确认后才保存并记录回执。
- 浏览器：服务重启后权限重置，故事草稿及已准备的方案恢复。
- 自动证据：缺少 Playwright 专用浏览器时改用已安装 Chrome，成功记录画布、开始按钮、运行日志与截图；页面仍要求人工确认玩法。
- 素材：通过文件选择器上传测试截图，候选图片真实显示，明确标注仅供参考、不代表已替换模型。
- 新入口：成功分析并启动已有 Three.js 游戏，使用独立工作台输出目录，没有应用任何真实游戏修改。

## 本轮发现并修复

- macOS `/var` 与 `/private/var` 临时目录别名触发了复杂预览路径误判：统一真实路径。
- Playwright 包存在但浏览器缺失：使用已安装 Chrome 后备路径，并保留失败状态。
- 图标 404 不应冒充游戏运行错误：记录为带地址的警告，其他错误继续阻止通过。
- 新版素材请求命名与既有供应商契约不一致：统一 `image.generate` / `image.edit` / `model.generate`。
- 新版发布包不能依赖私人游戏快照跑测试：换用可分发的合成示例。
- 过期草稿在新保存时可能被覆盖：保留归档副本；验证前再次检查源码，防止沿用旧证据。
